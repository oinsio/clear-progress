# Rule: internationalization conventions

**Full guide:** docs/guides/i18n-guide.md

**Always:**
- Use `t()` from `useTranslation()` for all user-visible strings — never hardcode text in JSX
- Add keys to **both** `src/locales/ru.json` and `src/locales/en.json`
- Use flat two-level namespacing: `domain.specificKey` (e.g., `task.addPlaceholder`)
- For pluralization: provide `_one`, `_few`, `_many` suffixes for Russian; `_one`, `_other` for English
- For ordinals: use `ordinal: true` with `count` and `_ordinal_*` suffixes

**What NOT to do:**
- Do not add keys to only one locale file
- Do not create new namespaces unless it's clearly a new domain
- Do not use `dangerouslySetInnerHTML` for translated strings
