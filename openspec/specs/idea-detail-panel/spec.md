## Purpose

TBD — Detail panel for viewing and editing idea entities.

## Requirements

### Requirement: Idea description field icon

Idea description field label SHALL display the `FileText` icon to the left of the label text with `w-4 h-4` size. Implements FR16 of icons-for-task-detail.

#### Scenario: Idea description label shows FileText icon

- **WHEN** idea detail panel is open
- **THEN** the Description label displays the FileText icon to the left of the text
