## ADDED Requirements

### Requirement: Goal Details tab icon

Goal Details tab button SHALL display the `AlignLeft` icon to the left of the tab text with `w-4 h-4` size. Implements FR12 of icons-for-task-detail.

#### Scenario: Goal Details tab shows AlignLeft icon

- **WHEN** goal edit mode is open
- **THEN** the Details tab button displays the AlignLeft icon

### Requirement: Goal Attachments tab icon
